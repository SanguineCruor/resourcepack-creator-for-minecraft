## Обзор

Minecraft Resource Pack Builder — это однофайловый скрипт на Python, автоматизирующий рутинные операции с ресурспаками Minecraft:

- Генерация стартовой папки пака с `pack.mcmeta` и заготовкой `pack.png`.
- Упаковка папки пака в готовый к использованию `.zip`-архив.
- Проверка структуры папок и метаданных `pack.mcmeta`.
- Интерактивный выбор целевой версии Minecraft с автоматическим определением `pack_format`.
- Ручное переопределение значений `pack_format` или `min_format`/`max_format`.
- Двуязычные запросы (английский/русский) в зависимости от системной локали.

## Установка

Скачайте `resourcepack_builder.py` и запустите через Python 3.10+:

```bash
python resourcepack_builder.py --help
```

## Команды

### init

Создаёт новую папку ресурспака со стартовой структурой.

```bash
python resourcepack_builder.py init my_pack
```

Команда запрашивает название пака, описание, автора и целевую версию Minecraft (интерактивная таблица).

Параметры:

| Параметр | Описание |
|---|---|
| `--version "<версия>"` | Целевая версия Minecraft, например `"1.21.11"` или `"1.20 - 1.20.1"`; также принимается числовой индекс из таблицы версий |
| `--pack-format <N>` | Ручное переопределение значения `pack_format` |
| `--name <строка>` | Название пака |
| `--description <строка>` | Описание пака |
| `--author <строка>` | Автор пака |

### build

Упаковывает папку ресурспака в `.zip`-архив.

```bash
python resourcepack_builder.py build my_pack -o my_pack.zip
```

Параметры:

| Параметр | Описание |
|---|---|
| `-o, --output <путь>` | Выходной ZIP-файл (по умолчанию: `resourcepack.zip`) |
| `--icon <путь>` | Необязательный файл иконки пака, сохраняется как `pack.png` |
| `--name <строка>` | Название пака при генерации `pack.mcmeta` |
| `--description <строка>` | Описание пака при генерации `pack.mcmeta` |
| `--author <строка>` | Автор пака |
| `--version "<версия>"` | Целевая версия Minecraft |
| `--pack-format <N>` | Ручное переопределение значения `pack_format` |

Если `pack.mcmeta` в исходной папке отсутствует, он генерируется автоматически на основе переданных параметров и значений по умолчанию.

### validate

Проверяет структуру папки ресурспака и метаданные.

```bash
python resourcepack_builder.py validate my_pack
```

Проверка включает:

- Наличие папки пака.
- Наличие и валидность JSON в `pack.mcmeta`.
- Наличие `pack_format` либо пары `min_format`/`max_format` в секции `pack`.
- Наличие структуры папок `assets/minecraft`.

### formats

Выводит полную справочную таблицу версий Minecraft и соответствующих номеров pack format.

```bash
python resourcepack_builder.py formats
```

### help

Выводит общий обзор команд.

```bash
python resourcepack_builder.py help
```

## Генерация pack.mcmeta

Утилита автоматически формирует `pack.mcmeta` в одном из двух стилей:

| Стиль | Применимые версии | Поля |
|---|---|---|
| Устаревший | 1.6.1 – 1.21.8 | `pack_format` |
| Современный | 1.21.9 и новее | `min_format`, `max_format` |

Интерактивная таблица версий автоматически выбирает подходящий стиль и значения. Ручное переопределение доступно через `--pack-format`.

## Структура папок

```
my_pack/
├── pack.mcmeta          (генерируется автоматически)
├── pack.png             (пользовательская иконка, 256x256)
└── assets/minecraft/
    ├── textures/block/     (файлы .png)
    ├── textures/item/
    ├── sounds/             (файлы .ogg)
    ├── models/
    ├── font/
    └── lang/
```

## Решение проблем

| Симптом | Решение |
|---|---|
| `pack.mcmeta` определяется как некорректный | Проверьте синтаксис JSON и наличие секции `pack` с `pack_format` либо `min_format`/`max_format` |
| `No assets/minecraft folder structure found` | Создайте папку `assets/minecraft` внутри пака |
| Minecraft не загружает пак | Запустите `validate` и убедитесь, что `pack_format` соответствует целевой версии игры |
